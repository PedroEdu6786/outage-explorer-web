# Implementation specifications

## Outage Explorer web client

Start with the [web-client planning index](web-client/README.md). It contains the
Figma-derived four-view inventory, council-reviewed specification/design and
atomic-first task sequence for parallel development.

The accepted sequence is shared atomic components, independently owned feature
compositions, a composed fixture checkpoint, then individual pages. The user
confirmed fixture demos first and live integration before release. This is a
planning handoff; no application implementation has been completed.
